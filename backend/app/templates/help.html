Help & How Things Work

What this app does

This web application provides sensory-friendly map navigation for Melbourne CBD designed to help neurodivergent users find low-stimulation walking paths.

Core Features

  1. Real-Time Map: Displays live crowd conditions across Melbourne CBD using color-coded sensory dots (🟢 Calm, 🟡 Moderate, 🔴 Busy). Type starting & destination addresses to automatically compare the shortest path with recommended calm routes.
  2. Predict Future Crowd: Check whether any address or location in Melbourne CBD will be quiet or crowded at a specific future date & time using machine learning models.

Sensory Status Labels

  • 🟢 Calm (Quiet): Low crowd density — peaceful, low-noise environment.
  • 🟡 Moderate Activity: Noticeable movement and activity.
  • 🔴 Busy / Overstimulating: High crowd density — potential sound & visual stimulation.

Accessibility Controls

  • High contrast: The button in the top-right switches to a high-contrast theme. Your choice is remembered.
  • Text size: The A- and A+ buttons adjust all text sizes.
  • No animations or flashing: Motion-free design to prevent sensory overload.
  • Colour is never the only cue: Every sensory level includes an explicit text badge.
  • Keyboard navigation: Fully navigable using Tab and Enter/Space.
